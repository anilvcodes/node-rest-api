Node.js API Projects

This repository contains a collection of backend API projects built with Node.js and Express.js. Each project focuses on a different use case and is maintained as a separate API.

Projects
🔐 Auth API — auth-api

A basic authentication API for handling user registration, login, authentication, and user-related operations.

📝 Blog API — blog-api

A RESTful blog API for managing blog posts. It includes basic CRUD operations such as creating, reading, updating, and deleting posts.

🤖 AI API — ai-api

A basic AI-focused API designed to provide AI-related functionality through backend endpoints and can be extended with different AI services or models.

Getting Started

Each folder is an independent Node.js project.

cd auth-api
npm install
npm run dev


You can use the same commands inside blog-api or ai-api.

Purpose

These projects are created to practice and demonstrate backend development, REST API design, authentication, CRUD operations, and AI API integration using Node.js.
